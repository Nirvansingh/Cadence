04. STEP-BY-STEP EXECUTION GUIDE: BUILDING THE NEW APP
================================================================================
Project: Next-Gen Open-Source Productivity Suite & Hybrid SaaS
Target: Scaffolding a standalone production repository from scratch.

This guide outlines exactly how to initialize your new project folder and migrate
the tested components from this personal sandbox.

================================================================================
PHASE 1: SCAFFOLDING THE NEW REPOSITORY
================================================================================

Step 1.1: Choose Project Name
  Recommended public names:
  - "Cadence" (Rhythm, schedule, habits)
  - "Aura OS" (Calm, personal daily workspace)
  - "Nexus Tools" (Connected tools for learners)
  - "OpenRoutine" / "FocusForge"

Step 1.2: Initialize Project Folder
  Open terminal in your projects directory (e.g., C:\Users\nirva\Projects) and run:

  For Tauri + React + TypeScript (Recommended):
  ```bash
  npm create tauri-app@latest cadence-app -- --template react-ts
  cd cadence-app
  npm install
  ```

  Or for Next.js / React (Web + PWA first):
  ```bash
  npx create-next-app@latest cadence-app --typescript --tailwind --app
  cd cadence-app
  ```

PHASE 4: PACKAGING & RELEASING THE OPEN-SOURCE APP
================================================================================

Step 4.1: Test Locally in Desktop Mode
  ```bash
  npm run tauri dev
  ```
  This boots up a blazing-fast native Windows window running your application!

Step 4.2: Build Standalone Windows Installer (.exe / .msi)
  ```bash
  npm run tauri build
  ```
  Tauri will compile a production `.exe` and `.msi` inside `src-tauri/target/release/bundle/`.
  This file is around 10MB and can be shared directly with friends, classmates, or on GitHub.

Step 4.3: Publish to GitHub
  ```bash
  git init
  git add .
  git commit -m "feat: initial commit of Cadence open source productivity suite"
  git branch -M main
  git remote add origin https://github.com/your-username/cadence.git
  git push -u origin main
  ```

Step 4.4: Add GitHub Release Automation (CI/CD)
  - Set up a GitHub Action (`.github/workflows/release.yml`) using `tauri-action`.
  - Every time you create a GitHub release tag (e.g. `v1.0.0`), GitHub automatically
    builds Windows, macOS, and Linux installers and uploads them as download assets!
